Logic Simulation circuit exchange

IMPORT:
  Put .logicbundle.json or .logicchip.json files in the import folder,
  then click IMPORT FILES in the circuit editor. Successfully imported
  files are moved to processed.

EXPORT:
  Select a saved chip in MY CHIPS and click EXPORT SELECTED. The editor
  writes a readable .logicbundle.json containing that chip and all custom
  chip dependencies into the export folder.

The JSON is intentionally portable and readable by humans and tools.
